浏览器自动填写插件

在企业校招官网登录后，点页面右下角的「秋」悬浮按钮，选择简历即可 AI 自动填写表单。

安装步骤（一次性，Edge / Chrome 通用）：

  1. 浏览器地址栏打开 edge://extensions（Chrome 为 chrome://extensions）
  2. 打开左侧「开发人员模式」开关
  3. 点「加载解压缩的扩展」，选择本项目下的 extension 文件夹
  4. 保持本服务运行（插件通过 127.0.0.1:8000 读取简历和调用 AI）

仅电脑端可用；填写结果会绿色高亮，请检查后再自行提交。

邮箱进度同步
